# 排版规范（WORD）

> 依据单位公文版式惯例与国网汇报材料规范整理。本文是 sgcc-writer 的**排版单一事实源**；文风、句式、口吻见 reference-style.md。
>
> **使用约定**：`〔 〕`为结构占位，成品前必须替换；`【 】`为用户未提供的事实，交付时列清单。本文示例均为演示值或虚构值，不涉及真实文档与真实数据。

## 0. 适用范围与路径

**适用**：Word 文档排版，统一使用国网预设。任何 Word 文档均可使用，非国网文档也套国网预设，并在回执注明。原生处理 `.docx`；`.doc` 先转换为 `.docx` 再排版；`.docm` 建议另存为 `.docx` 后处理。

| 格式 | 说明 | 处理方式 |
|---|---|---|
| `.docx` | Office Open XML，2007 及以后版本的默认格式，现代 Word/WPS 可直接读写 | 原生处理，推荐交付格式 |
| `.doc` | Word 97-2003 / WPS 旧版二进制格式，现代工具需转换 | 先用 Word/WPS/LibreOffice 另存为 `.docx`，再排版 |
| `.docm` | 含宏的 OOXML 文档 | 先另存为 `.docx`（不带宏），再排版；不执行宏 |

交付默认 `.docx`；用户明确要求 `.doc` 时，排版完成后再另存为 `.doc`，并提示旧格式可能丢失部分样式或功能。

**不适用**：PPT、PDF、红头公文（通知、印发、主送、版记等）。

**三条排版路径**：

| 路径 | 信号 | 处理 |
|---|---|---|
| 纯排版 | 有底稿，用户说“排版/统一格式/套模板/格式整理”，不要求改内容 | 只调格式，不动内容 |
| 生成即排版 | 起草、参照重写完成 | 生成时按依据套排版 |
| 改稿后排版 | 用户既要改内容，又说“改完再排版” | 先改内容，再确定排版依据 |

**改稿仅内容**（润色、顺句、按批注修改，不提排版）：沿用原稿格式，不自动重排。

## 1. 排版依据与默认规则

### 1.1 依据优先级

1. 用户明确指定的模板或格式；
2. **国网预设**（本技能唯一排版预设，适用于所有文档）；
3. **原稿体例**（仅改稿后排版、用户未指定目标时；保留原稿，不套国网预设）。

### 1.2 默认规则

- **纯排版，无明确目标** → **国网预设**（所有文档；非国网文档也在回执注明“国网预设（非国网文档）”）。
- **改稿后排版，无明确目标** → **原稿体例**，不套国网预设；回执写明，并提示可改用国网预设重排。
- **明确说“按国网/按你们的格式”** → 国网预设。
- **明确说“按XX模板”** → 用户模板；模板缺项用国网预设补齐，并在回执说明补齐项。
- **无法判断文档类型** → 国网预设；回执注明判断依据。

### 1.3 “原稿体例”的定义

沿用原稿的页面设置、字体字号体系、标题层级、图表题注和页码方式；原稿内部不一致处，按主样式归一；**不引入新模板、不换字体体系**。

原稿没有稳定样式、无法沿用时，按国网预设重排，并在回执说明“原稿无稳定样式，改用国网预设”。

## 2. 国网预设（guowang）

### 2.1 页面

| 项目 | 值 |
|---|---|
| 纸张 | A4（21.0 × 29.7 cm） |
| 页边距 | 上 3.7cm／下 3.5cm／左 2.8cm／右 2.6cm |
| 页眉距边界 | 1.5cm |
| 页脚距边界 | 2.5cm |
| 版心目标 | 每面约 22 行、每行约 28 字 |

版心目标是验收参考，不强制写死文档网格；以导出 PDF 目检为准。工具支持字符网格时可设置，工具不支持时不强求，回执注明实际效果。

### 2.2 字体字号

| 用途 | 字体 | 字号 | 加粗 | 对齐/缩进 |
|---|---|---|---|---|
| 标题 | 方正小标宋_GBK | 二号 22pt | 否 | 居中，段后约 22pt（1 行） |
| 一级标题（一、） | 黑体 | 三号 16pt | 否 | 顶格 |
| 二级标题（（一）） | 楷体_GB2312 | 三号 16pt | 是 | 顶格 |
| 三级标题（1.） | 仿宋_GB2312 | 三号 16pt | 是 | 顶格 |
| 四级标题（（1）） | 仿宋_GB2312 | 三号 16pt | 是 | 顶格 |
| 正文 | 仿宋_GB2312 | 三号 16pt | 否 | 两端对齐，首行缩进 2 字符，固定行距 28pt |
| 表名 | 宋体 | 四号 14pt | 是 | 居中，置于表上方 |
| 表内文字 | 宋体 | 小四 12pt | 否 | 表头居中加粗，表内不缩进 |
| 图名 | 宋体 | 四号 14pt | 是 | 居中，置于图下方 |
| 页码 | 宋体 | 四号 14pt | 否 | 居中 |
| 页眉 | 仿宋_GB2312 | 小五 10.5pt | 否 | 右对齐 |
| 落款 | 仿宋_GB2312 | 三号 16pt | 否 | 右对齐 |

**行距以 28pt 为准**。28.95pt 仅作参考，不采用；22.7pt 不采用。

首行缩进优先用 `firstLineChars=200`（2 字符）；工具不支持字符缩进时，按 16pt 字号折算约 32pt（640 twips），回执注明实现方式。

### 2.3 标题与编号

- 编号链：`一、` → `（一）` → `1.` → `（1）`；第五层不设标题，用行内“一是…二是…”。
- 标题一律顶格，不加首行缩进；编号与标题之间不留空格。
- 标题不加句号；长标题可断行，断行处不加标点。
- 层级不得跳级；任务N/问题N可跨章连续，不按章重置。
- 标题文字保持用户原文，排版不改写、不缩写。

### 2.4 页码

- 默认格式：`—N—`，宋体四号，居中。
- 备选格式：`-N-`，仅在用户指定或工具只支持该格式时使用，回执注明。
- 封面不编码；正文起编；目录页编码方式按用户模板，未指定时与正文连续。
- 页码放在页脚，页脚距边界 2.5cm；工具不支持精确页脚距离时，回执注明。

### 2.5 表格

- 表名置于表上方，宋体四号加粗居中，格式“表N 〔表名〕”。
- 表内文字宋体小四；表头加粗居中；表内不缩进，行距单倍。
- 跨页表重复表头行；合并单元格保持原样。
- 三线表：顶线、表头底线、底线；无竖线。线宽参考：顶线/底线 1.5pt，表头底线 0.75pt；工具不支持精确线宽时按三线表结构处理并注明。
- 表格居中，最大宽度不超过版心（约 16cm）；超宽表优先缩列宽，不缩字号到不可读。
- 表内数字、单位、口径不得改动；只调格式。

### 2.6 图

- 图名置于图下方，宋体四号加粗居中，格式“图N 〔图名〕”。
- 图片居中，最大宽度约 15cm，保持纵横比，不拉伸变形。
- 图内文字、图注、数据不得改动；只调位置、尺寸和题注格式。

### 2.7 目录

- 默认不主动生成；用户要求或原稿已有目录时才生成。
- 目录标题“目录”，方正小标宋_GBK 二号 22pt，居中。
- 目录层级 1–4 级；页码右对齐，点线引导。
- 目录是 Word 域，打开后需在 Word/WPS 中“更新域”；交付时提醒用户。
- 工具无法生成可更新目录时，留占位并告知，不伪造页码。

### 2.8 页眉与落款

- **默认不添加**页眉和落款；用户明确要求时才加。
- 页眉：仿宋_GB2312 小五 10.5pt，右对齐，文字为单位名或用户指定文字。
- 落款：仿宋_GB2312 三号 16pt，右对齐；单位名 + 日期，日期格式按用户要求，未指定用阿拉伯数字。
- 内部材料默认不落款（内容约定）；正式材料需要落款时按本节执行。

### 2.9 附件

- 正文引用保留我方写法：正文括注“（详见附件N）”，文末“附件N：〔附件名〕”。
- 正式版可采用“附件：1. 〔附件名〕”的编号写法；同一文档内只用一种，不混用。
- 附件本体另起一页；“附件”二字及序号用三号黑体顶格于版心左上角第一行，附件标题居中于第三行。
- 多个附件按顺序编号；附件内正文、表格、图沿用本预设。
- 附件正文内容不得改动。

### 2.10 标点与清理

- 中文正文使用全角标点。
- 只清理行首装饰性项目符号 `○`、`●`、`•`、`·`；保留正常编号和列表语义，清理数量写入回执。
- 不自动改写代码、URL、英文缩写、数字公式中的标点。
- 标点全角化默认只检查提示，不自动替换；用户明确要求时才改，并列出改动。

### 2.11 字体回退

按以下顺序请求字体；缺失时逐级回退，并在回执中说明：

| 目标字体 | 回退 1 | 回退 2 |
|---|---|---|
| 方正小标宋_GBK | 宋体 | SimSun |
| 仿宋_GB2312 | 仿宋 | FangSong |
| 楷体_GB2312 | 楷体 | KaiTi |
| 黑体 | SimHei | 无 |
| 宋体 | SimSun | 无 |

不自动安装字体；字体缺失只提示，不静默替换后当作已完成。

### 2.12 内容保全

- 排版不改写、不增删、不调整数据和事实；只调格式。
- 保留表格、图片、页眉页脚、脚注、尾注、批注、修订痕迹、书签和交叉引用。
- 含批注/修订的文档，默认保留原状；工具无法保留时停止并报告，不擅自接受或删除修订。
- 文本框、艺术字、复杂合并表、嵌入对象等复杂结构按 B/C 级保障处理；无法完整保留时停止并说明。
- 交付前做文本对比：正文只允许“行首装饰符清理、空白归一”等已声明变更；其他差异视为失败并返工。
- 表格数量、图片数量、附件数量与排版前一致；如不一致，停止交付。

## 3. 非国网文档

非国网文档使用本技能排版时，同样套国网预设；回执写“国网预设（非国网文档）”。

例外只有两种：

- 用户提供模板 → 按用户模板，缺项用国网预设补齐；
- 改稿后排版且用户未指定目标 → 沿用原稿体例，不套国网预设。

## 4. 执行步骤（agent 按此做）

**输入格式**：`.docx` 直接处理；`.doc`/`.docm` 先由 Word/WPS/LibreOffice 另存为 `.docx`，再排版；无法转换时请用户先另存。

1. **定依据**：国网预设／原稿体例／用户模板，并在开工前告知用户。
2. **读参数**：按本文列出本次要应用的页面、字体、字号、行距、标题、页码、表格、图、附件、页眉/落款。
3. **选工具**：按 4.1 的能力顺序选择，不绑定具体名称。
4. **执行**：只改格式，不改内容；保留表格、图片、页眉页脚、脚注、批注和修订。
5. **验收**：按第 6 节 D1–D7 自检；用 PDF 目检分页、表格跨页、图片位置。
6. **交付**：文件 + 排版回执；执行方式、未应用项、字体回退、警告全部写明。

使用任何模板或工具时，参数以本文件为准；工具默认值与本文件冲突时，以本文件为准。

### 4.1 工具兜底（按顺序）

1. **本地 Word 文档处理能力**：能读写 `.docx`、保留表格/图片/批注/修订即可，名称不限（Office 文档 MCP、Word 文档处理技能、Word/WPS 自动化、能读写 docx 的脚本库等均可）。
2. **Python + python-docx 兜底**：本地一个 Word 能力都没有时，用 agent 运行时 Python 按本文参数执行一次性格式化；缺包时安装 `python-docx`。这只是兜底执行，不把脚本沉淀为技能引擎。
3. **仅规范/模板**：Python 也不可用时，交付格式规范 + 模板/操作步骤，由用户在 Word/WPS 中套用；必须明确告知“未自动排版”，不得声称已完成。

全程本地处理，不上传文档。

### 4.2 补齐能力（只按能力搜索，不绑定名称）

- Qoder Desktop：扩展/技能市场搜索 `docx`、`Word`，选能读写 `.docx`、保留批注/修订的能力；
- SkillHub：`skillhub search docx`，再 `skillhub install <匹配到的 slug> --dir <skills 目录>`；
- 只需脚本能力：`python -m pip install python-docx`。Windows 用 `python`，不要用 Store 占位符 `python3`；Linux/macOS 用 `python3`。

未应用：页眉、落款、目录（默认关闭）。

可改用：如需按国网预设重排，我可以另出一版，不覆盖本版。

### 5.4 必填字段

任何回执必须包含：**排版依据、执行方式、已应用项、未应用项、字体回退、校验结果**。漏任何一项视为不合格。

## 6. 验收清单（D）

### D1 依据与回执

- 排版依据明确（国网预设/原稿体例/用户模板）。
- 开工前已告知；交付回执已附，六类必填字段齐全（含执行方式）。

### D2 页面

- A4；国网预设边距 3.7/3.5/2.8/2.6cm；页眉 1.5cm、页脚 2.5cm。
- 22 行 × 28 字目标已目检；分页无孤行、无异常空白页。

### D3 标题

- 标题字体、字号、字重、居中、段后间距符合依据。
- 一级至四级标题字体、字号、字重、顶格、编号链正确；无跳级。
- 标题文字未被改写。

### D4 正文

- 正文字体、字号、行距、首行缩进、对齐方式符合依据。
- 国网预设：仿宋_GB2312 16pt、固定 28pt、首行 2 字符、两端对齐。
- 字体回退已记录。

### D5 页码、表格、图、目录、附件、页眉落款

- 页码格式、字体、位置正确；目录/附件如启用，格式正确。
- 表格：表名位置/字体、表头重复、三线表、限宽、合并单元格保持。
- 图：图名位置/字体、图片居中、限宽、比例保持。
- 页眉/落款：未擅自添加；如需添加，格式正确。

### D6 内容零改动

- 正文、表格、图片、脚注、批注、修订与排版前一致。
- 只允许已声明的清理（行首装饰符、空白归一）；其他差异为零。
- 表格/图片/附件数量与排版前一致。

### D7 命名与归档

- 纯排版：`原名-排版-〔依据〕-YYYYMMDD.docx`。
- 预设重排：`原名-排版-国网预设-YYYYMMDD.docx`；不覆盖原稿体例版。
- 原稿移入同目录 `历史版本/`；当前目录保留最新交付稿。

## 7. 保障级别

| 级别 | 场景 | 承诺 |
|---|---|---|
| A级 | 新生成文档 | 按本文完整执行并验收 |
| B级 | 已有 docx，普通段落/表格/图片 | 内容不变，按依据重排；复杂结构 best-effort |
| C级 | 文本框、复杂合并表、复杂目录、嵌入对象、扫描件 | 人工复核，不承诺一键完成 |

级别写入回执；B/C 级必须列出未处理项，不能只说“已排版”。

## 8. 边界与失败处理

- 仅 WORD：`.docx` 原生处理；`.doc`/`.docm` 需先转换为 `.docx`；PPT、PDF、红头公文不在范围。
- 所有排版统一国网预设（用户模板除外）；非国网文档也按国网预设。
- 工具不可用：改用本地其它可用的 Word 文档处理能力或 Word/WPS；仍不可用则停止并说明。
- 文档太复杂、无法保留结构：保留原稿，报告未完成项，不硬改。
- 用户要求改内容：先走改稿/起草路径，最后再排版；排版模式不代写内容。
- 用户要求“排得好看点”但没有目标：按第 1.2 节默认执行，并告知依据。
