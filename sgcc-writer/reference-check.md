# 交稿自检（A/B/C/D）

> 本文件是 sgcc-writer 的自检单一事实源；SKILL.md 只保留入口与路径组合。
>
> 路径组合：起草 A+B1+C+D；改稿仅内容 A+B2+C；改稿后排版 A+B2+C+D；纯排版 D+C。

## A 共用硬伤（内容路径都过，一票否决）

- **A1 数字一致**：同一指标全文一个值/口径/单位；分项之和＝合计、占比×基数＝分项、增长率可复算；附件表与正文同源；每个数字能在《内容来源清单》找到出处，找不到已改【 】；未搬用参考文件或 examples 的示例数字。
- **A2 时间一致**：年份/节点与用户时间坐标一致，无示例年份残留；里程碑先后不矛盾；文件名日期、正文日期、封面年月三者一致。
- **A3 主体与称谓一致**：首次"国家电网有限公司（以下简称'公司'）"后统一"公司"；单位名称、部门、职务按用户提供写法，未被误改。
- **A4 引文可溯源**：领导讲话、政策文件、外部报告：原文＋出处＋日期齐全；不把转述写成引号直引。
- **A5 无虚构、无残留**：无编造数据/文号/人名/日期；无 TODO/待补充/待确认/审稿批注；未出现参考文件或 examples 的具体专名、提法、文号、引文；【 】已列清单，〔 〕已替换完毕。
- **A6 对外口吻**（仅对外材料）：无"请领导审议/请支持/要求/务必/压实"等内部指令口吻；成绩留余地（初步建成/试点应用/约X%）。

## B1 起草体例（仅起草/参照重写）

- **B1-1 编号链**：一、→（一）→1.→（1）→一是二是，无跳级；任务N/问题N跨章连续。
- **B1-2 文体边界**：方案有"特制定本方案"；汇报无"工作目标"章与任务分工表；总结必须有"存在的问题"和"下一年安排"。
- **B1-3 关键句式**：目标章优先3个以上量化指标，数据不足时用【 】列缺口且不编造；收尾句"支撑X，为公司Y筑牢Z"可选，无合适战略落点时不强套。思路章有口诀时首次括注展开，无现成提法时不硬造；保障条目优先对仗双句，末条按内容收口，不强制"落地见效"。
- **B1-4 问题表述**："仍/尚未/有待/面对…挑战"，无"缺陷/失误"定性；"短板"仅对外材料可用且须紧跟解法。
- **B1-5 标题与落款**：标题优先动宾结构，便于一眼看出"做什么、达到什么"；带引号概括语、长标题或专名可例外，断行处不加标点；内部材料无落款。

## B2 改稿体例（仅改稿）

- **B2-1 基线清楚**：交付说明写出"基于哪个文件、哪一版"；以最新附件为基线，不沿用上一轮底稿。
- **B2-2 范围与批注覆盖**：附"批注覆盖表"（编号—意见—处理结果—未处理原因）；范围外批注原样保留，未点名内容未动。
- **B2-3 修订保护**：含 `w:ins` 的段落未整段重写；用户已插入文字未被覆盖；新建 run 无 `w:rPrChange`。
- **B2-4 批注锚点**：批注总条数一致；每条有可定位锚点；锚点未挂错章节；未代答、未合并、未改作者。
- **B2-5 图表与脚注**：图号/表号连续；删除图表后引用与空壳同步清理；图随题注、表头跨页重复、脚注正常。
- **B2-6 目检**：导出 PDF 逐页看分页、跨页表格和图片位置。
- **B2-7 变更对照**：附"原→新"变更表（位置、原文、改后、依据），只列改动项。
- **B2-8 修订模式**：默认带 `w:ins` / `w:del`；如另出干净稿，未覆盖修订版。

## C 共用交付（内容路径都过）

- **C1 版本与命名**：起草按 `【YYYY.MM.DD】主题+文种_Vn.n`；改稿按原名 + `-YYYYMMDD-vN`，原文件有版本则递增，无版本从 v1 起；排版任务命名见 D7。
- **C2 备份与归档**：改前备份到同目录 `历史版本/`；交付后旧稿（含基线稿）归档，当前目录只留最新稿；只归档本次目标文档，不动同目录其它文件；排版任务归档见 D7。
- **C3 保存与回复**：保存位置符合 SKILL.md 第四步优先级；只有成品在交付位置，过程文件已归入 `产物/`；回复含绝对路径、字数与页数、占位符数量；起草附内容来源清单，改稿附基线与变更对照（B2-1、B2-7）；排版任务回执见 D1。

## D 排版（纯排版 / 生成即排版 / 改稿后排版）

- **D1 依据与回执**：排版依据明确（国网预设／原稿体例／用户模板）；预检已完成（绿/黄/红，见 reference-runtime.md），字体精确/回退/缺失结论、模板版本/来源已记录；开工前已告知；回执含依据、预检、执行方式、已应用、未应用、字体回退、异常/降级、校验。
- **D2 页面**：A4；国网预设边距 3.7/3.5/2.8/2.6cm；页眉 1.5cm、页脚 2.5cm；22 行×28 字目标已目检，分页无孤行、无异常空白页。
- **D3 标题**：标题字体、字号、字重、居中、段后间距符合依据；一至四级标题字体、字号、字重、顶格、编号链正确，无跳级；标题文字未被改写。
- **D4 正文**：字体、字号、行距、首行缩进、对齐符合依据；国网预设为仿宋_GB2312 16pt、固定 28pt、首行 2 字符、两端对齐；字体回退已记录，回退时实际使用回退字体名并与预检 `actual` 一致。
- **D5 页码、表格、图、目录、附件、页眉落款**：页码格式/字体/位置正确；表名位置与字体、表头重复、三线表、限宽、合并单元格正确；图名位置/字体、图片居中/限宽/比例正确；目录域可更新；附件格式正确；页眉/落款未擅自添加，如需添加格式正确。
- **D6 内容零改动**：正文、表格、图片、脚注、批注、修订与排版前一致；只允许已声明的清理（行首装饰符、空白归一）；表格/图片/附件数量与排版前一致；差异为零或已逐条报告。
- **D7 命名与归档**：纯排版为 `原名-排版-〔依据〕-YYYYMMDD.docx`；预设重排为 `原名-排版-国网预设-YYYYMMDD.docx`；原稿移入 `历史版本/`；两个排版版本都保留时用依据区分，不互相覆盖。
- **D8 模板示例残留**：交付文档无 `【示例`、`示例正文`、`模板样式示例页` 等标记；发现残留已提示用户处理，未自动删除。

## 可机器核对

A5、B1-1、C1、D2–D8 交付前用检索/读取核对：搜 `TODO|待补充|待确认`、查编号跳号、核对文件名与正文年月、核对页面/字体/页码/表图数量、扫描模板示例残留。
