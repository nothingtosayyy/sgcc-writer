# 书面工作汇报（WORD）写作模板

> 依据汇报类写作惯例整理。与方案的区别：**汇报重"做了什么、效果如何"（完成体），方案重"要做什么、怎么分工"（将来体）**。禁用"特制定本方案""工作目标"章、任务分工表。

> **使用约定**：本文件只写规则与占位骨架；`〔 〕`为结构占位，`【 】`为用户未提供的事实。需要语感时读 `examples/语感示例.md`，其中内容不得复用。
>
> **免责声明**：本文示例均为体例演示，内容为演示值或虚构值，不涉及真实文档与真实数据。

## 0. 提问清单（生成前必问）

1. 亚型：回顾总结型（讲已有做法成效）／前瞻举措型（讲下一步怎么干）／总结型（年度或专项工作总结）？
2. 汇报对象与依据："根据XX总关于……的工作部署"或"深入贯彻……决策部署"——导语必需
3. 成效数据：核心数字清单（规模/效率/覆盖/人数），越具体越好
4. 工作思路口诀：有没有现成提法？没有则用平实一句话概括，不硬造"N个X"
5. 做法分几块？（惯例3块，每块带引号概括语）
6. 下一步：3–4条，有无高站位收束点（〔高站位主题〕）
7. 有无附件（表格支撑材料）？

## 1. 标准回顾型骨架（约4500字基准，正文约8页）

```
标题（两种写法："关于+事由+的+工作汇报" 或 "单位全称+事由+工作汇报"分行）
[导语段×2，约380字，8%]
  第一段（戴帽子）："〔单位全称〕（以下简称'〔简称〕'）深入贯彻〔上级部署〕，
  全面落实〔专项行动/工作要求〕，……形成'〔A〕+〔B〕+〔C〕'
  三位一体的〔领域〕建设布局。"
  第二段（总体概览）："于〔年份〕〔月〕依托……成立……实现〔指标〕〔数值+单位〕……初步建成……"
一、工作思路（约150字，3%）——有现成口诀时用一句总揽："按照'〔数字口诀〕'的工作思路"；没有时不硬造，用一句话概括总体思路 + 图1
二、典型做法（占全文约74%，绝对重心）
  （一）"〔A〕+〔B〕"概括语标题（引号词组+定性词）
      1. 动宾小标题（"打造'〔A〕+〔B〕'〔机制名〕"）
      2. 动宾小标题
      —— 每条内部按"针对/面对……问题 → 机制/做法 → 量化成效"微循环
  （二）……  （三）……（惯例3块）
三、下一步工作安排（约570字，14%）
  [时间锚+"一是…二是…三是…四是…"，每条动宾命名]
附件（如有）："附件：XXX"，表格以"表1 XX"编号
```

**做法小节的微循环模板**：
> "面对〔领域〕〔问题1〕、〔问题2〕、〔问题3〕等挑战，横向打通〔渠道〕，……构建了职责界面明确、任务分工清晰的〔N〕人〔团队〕，实现〔对象〕〔数量〕（〔容量〕）的归集入库。"

### 1.1 总结变体（年度／专项工作总结）

与标准回顾型的三处差异：
1. 主体章由"典型做法"改为"全年工作回顾"，按板块或条线分3–4块，仍用"针对问题→做法→成效"微循环。
2. 必须单设"存在的问题"一节，不内嵌；每条以"仍／尚未／有待"收尾。
3. 末章由"下一步工作安排"改为"下一年工作思路"，3–4条动宾排比，带量化承诺。

```
标题（〔单位〕〔年份〕〔主题〕工作总结）
[导语] 时间背景 + 总体成效一句 + "现将全年工作总结如下。"
一、全年工作回顾（（一）（二）（三），每块带引号概括语）
二、主要成效（3–5个量化；也可并入各回顾块尾）
三、存在的问题（按维度分块，每条"仍/尚未/有待"收尾）
四、下一年工作思路（3–4条动宾+量化承诺）
（内部材料不落款）
```

**边界**：总结必须有"存在的问题"和"下一年安排"；不得只写成绩，也不得把"下一年思路"写成"下一步工作"。

## 2. 前瞻举措型骨架（约2300字基准，正文约4页，纯"下一步"汇报）

```
关于XX的下一步工作汇报
[导语段约120字]："根据〔领导〕关于XX的工作部署，〔部门〕深入调研……下一步工作举措如下。"
一是……（约420字超长段）
二是……（约430字）
三是……（约260字）
[结尾段]："后续XX部将充分做好技术支撑工作，为XX工作合规有序开展提供坚实保障。"
附件：支撑手续/表格
```
特征：全文可不设编号标题，主体即"一是/二是/三是"超长段；条目按工作逻辑链展开（组织职责→技术路径→合规底线）；收尾一句"表态+保障"。

## 3. 关键写法规则

- **成效副词分级**：硬成果"实现/已完成"；留余地"初步建成/现已具备"；数据密度：每个做法小节优先以1–2个数字收尾；没有合适数字时不要硬凑，改用覆盖范围、节点、对象数量等可核验事实。全文量化密度按材料类型调整，不强制每150字一处
- **数据四句式**：①"构建〔N〕人〔团队〕"（数字+名词）②"〔数量〕（〔容量〕）"（量与容量双括注）③"〔效率指标〕提升〔N%〕"④"按〔周期〕开展培训〔N〕期〔N〕人次"（N期N人次+时间锚）
- **问题不独立成章**：全部内嵌为做法引子（"面对/针对……等挑战/问题/矛盾"）；确需独立问题时每条紧跟改进方向，措辞落"有待/仍需/尚需"
- **下一步每条**：动宾短语命名（建立X机制/构建X体系/沉淀X模式/带动X共赢），3–4条为宜，至少一条落高站位（如〔高站位主题类表述〕），条内仍嵌量化承诺
- **无请求支持**：书面汇报默认不写"请领导支持"，需要资源支持另列"有关建议"或走请示文种
- **格式**：不写主送抬头、不落款；版本日期外置文件名；配图"图1 XX"独立成行；编号"一、/（一）/1./一是"

## 4. 特色句式库

- "以〔A〕为轴，以〔B〕为线，以〔C〕为点，实现〔对象〕一点发力、多处协同。"（空间隐喻三连）
- "通过'〔方式1〕+〔方式2〕+〔方式3〕'相结合的方式，实现〔能力〕的〔传递/提升〕。"（方式+成效因果句）
- "在〔层面1〕，……；在〔层面2〕，……；在〔层面3〕，……"（分层句）
- "〔部门A〕牵头统筹……，〔部门B〕立足技术支撑核心职能，……，〔部门C〕切实履行〔责任〕主体责任"（职责分工三段式：牵头统筹/立足职能/履行责任）
- 二级标题必带引号概括语："'〔A〕+〔B〕+〔C〕'〔定性〕〔对象〕"

## 5. 生成后自检（文体专属；数据/时间/称谓/引文/残留等硬伤按 SKILL.md 第五步 A 级核对，此处不重复）

- [ ] 导语有依据句+总体概览，无"特制定本方案"
- [ ] 典型做法占比≥70%，3块引号概括语标题对仗
- [ ] 每个做法有问题引子+机制+量化数字
- [ ] 下一步3–4条动宾排比+高站位收束+表态句
- [ ] 无落款；全文完成体时态
- [ ] 总结变体：有"存在的问题"和"下一年工作思路"两章，未写成"下一步工作"
