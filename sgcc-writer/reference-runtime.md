# 运行时规范（预检 / 模板 / 异常）

> 本文件承载 Word 任务的开工前预检、国网预设模板用法和统一异常处理；SKILL.md 只保留入口。
>
> 原则：绿色直接做，黄色先告知，红色先停止；异常先说明“未做什么”，再给“能做什么”。

## 1. 轻量预检

### 1.1 何时执行

任何 Word 任务开工前执行一次：起草、改稿、参照重写、纯排版。预检只读元数据和结构，不把全文读进上下文。

### 1.2 检查项

| 类别 | 检查内容 |
|---|---|
| 输入 | 文件存在、可读、扩展名（`.docx`/`.doc`/`.docm`）、大小、hash、是否加密/损坏、是否被占用 |
| 结构 | 段落数、表格数、图片数、文本框/形状、复杂合并表、批注/修订数量 |
| 工具 | 本地 Word 文档处理能力（技能/MCP/自动化）、Word/WPS 自动化、Python、`python-docx` |
| 字体 | 按注册表（HKLM/HKCU）和字体目录识别目标字体；区分精确命中、按规则回退、缺失 |
| 模板 | `assets/templates/guowang-preset-v1.0.1.docx` 是否存在、可打开、样式是否齐全 |
| 输出 | 目标目录可写、文件名是否冲突、磁盘空间 |
| 版本 | 基线版本、内容指纹；是否检测到外部修改 |

### 1.3 结果分级

- **绿色**：核心工具、模板齐全，字体精确命中或可回退；直接执行，只留一行回执。
- **黄色**：目标字体与回退均缺失、模板缺失、Python 兜底、复杂结构；可以执行，但先告知限制，回执记录。
- **红色**：无工具且无 Python、文件被占用/损坏、`.doc` 无法转换、输出不可写；停止，不写文件，给恢复路径。

### 1.4 用户提示

绿色：

```text
预检通过：输入 docx，工具可用，字体无缺失，模板可用；开始排版。
```

回退说明：

```text
预检说明：〔目标字体〕未安装，按规则使用〔替代字体〕；其余字体精确命中；继续排版，回执记录。
```

黄色：

```text
预检提示：本机缺〔目标字体〕且无已定义回退，将由 Word 替换；模板可用；
结构、字号、行距不变。继续排版，回执会记录字体替换。
```

红色：

```text
预检未通过：〔原因〕。未修改任何文件。可选：
1. 〔恢复路径1〕；
2. 〔恢复路径2〕；
3. 我只交付格式规范和模板，由你在 Word/WPS 中套用。
```

### 1.5 预检脚本

优先运行：

```bash
python scripts/preflight.py \
  --input "〔输入文件〕" \
  --template "assets/templates/guowang-preset-v1.0.1.docx" \
  --json
```

脚本只读文件、注册表、字体目录、模板和输出目录，返回 `level`（green/yellow/red）、`warnings`、`errors`、`fonts`（`targets` 区分 exact/fallback/missing）和结构计数；不修改文档。脚本不可用时，按 1.2 手工核对，但仍只做一次。

## 2. 国网预设模板

### 2.1 文件与定位

```text
assets/templates/guowang-preset-v1.0.1.docx
```

- 是**样式模板**，不是内容模板，不是排版引擎；
- 含页面设置、`GW-*` 段落样式、页脚页码域和一页样式示例；
- 不含真实数据、宏、外链或嵌入对象。

### 2.2 样式清单

`GW-Title`、`GW-H1`、`GW-H2`、`GW-H3`、`GW-H4`、`GW-Body`、`GW-TableCaption`、`GW-TableText`、`GW-TableHeader`、`GW-FigureCaption`、`GW-PageNumber`、`GW-Header`、`GW-Signature`、`GW-Attachment`、`GW-TOC`、`GW-Note`。

样式参数以 `reference-format.md` §2 为准。

### 2.3 用法

- Word/WPS：打开模板，粘贴内容后套用 `GW-*` 样式；或作为“应用模板”的样式源；
- Python/python-docx：以模板为 `Document` 基座，清掉示例占位后写入内容；
- 本地 Word MCP/自动化：作为 reference template / style source；
- 模板不可用：按 `reference-format.md` §2 的参数手工排版，回执注明“模板不可用，按参数排版”。

### 2.4 示例页与清理

模板第一页是样式示例，所有示例文字都带 `【示例…】` 标记：

- `【模板样式示例页】`
- `【示例标题】`
- `【示例一级标题】`～`【示例四级标题】`
- `【示例正文】`
- `【示例表名】`、`【示例表头】`、`【示例内容】`
- `【示例图名】`

交付前必须删除示例页。验收时扫描 `【示例`、`示例正文`、`模板样式示例页`；发现残留就提示，不自动删除。删除示例页后，样式仍保留在文档中。

## 3. 统一异常处理

### 3.1 异常卡模板

```text
【问题】一句话说明发生了什么
【影响】哪些内容/格式可能受影响
【已保留】原文件、备份、中间文件
【可选处理】1. … 2. …
【不会做】不覆盖、不删锁文件、不假装完成
```

### 3.2 异常清单

| 编号 | 触发 | 固定提示要点 | 恢复路径 |
|---|---|---|---|
| E01 文件被占用 | 读写报错、锁文件、权限拒绝 | “文件正被占用，未做任何修改。” | 关闭 Word/WPS 后重试；另存新文件；不改锁文件 |
| E02 字体缺失 | 目标字体与已定义回退均检测不到 | “本机缺〔字体〕且无已定义回退，将由 Word 替换；字号、行距、结构不变。” | 安装字体；接受替换；回执记录 |
| E03 工具不可用 | 无本地 Word 能力且 Python 不可用 | “未检测到可用 Word 处理能力，不会假装已排版。” | 启用本地能力；安装/启用 Word 工具；只给规范/模板 |
| E04 .doc 转换失败 | 旧格式无法打开或另存 | “旧版 .doc 无法转换，原文件未修改。” | 用户另存 `.docx`；换工具转换；停止 |
| E05 复杂结构无法保留 | 文本框、复杂合并表、嵌入对象 | “检测到复杂结构，当前工具无法完整保留，已停止。” | 换工具；人工处理；仅排版可保留部分 |
| E06 输入损坏/加密/格式不支持 | 打不开、解析失败 | “文件无法读取，未修改原文件。” | 提供可打开版本；解密；停止 |
| E07 模板缺失/不匹配 | 模板不存在或样式不符 | “模板不可用，将按国网预设参数手工排版，并在回执注明。” | 使用模板；参数排版；用户提供模板 |
| E08 校验未通过 | 内容改动、格式检查失败 | “校验未通过，未交付；已保留中间文件。” | 修复；降级；人工复核 |

字体回退不按异常处理：命中回退时按实际字体排版，回执写“目标→替代”，不降级。

### 3.3 使用规则

- 先说明“未做什么”，再给“能做什么”；
- 红色异常先停止，不在原文件上继续写；
- 不输出原始 traceback；
- 复杂结构无法保留时，不静默丢弃；
- 所有异常写入回执“异常/降级”行。

## 4. 回执增加项

排版回执在六项基础上增加两行：

```text
预检：绿色／黄色（关键限制）／红色（未执行）
异常/降级：无 / 字体回退：仿宋_GB2312→仿宋 / E05 复杂结构未处理
```

六项仍为：排版依据、执行方式、已应用项、未应用项、字体回退、校验结果。

## 5. 边界

- 只能检测已保存的修改；未保存的编辑不可见；
- 预检和模板不修改原文件；
- 模板示例残留只提示，不自动删除；
- 工具、字体、模板状态以本机实际检测为准；
- 复杂文档按 B/C 级保障，不承诺像素级一致。
