# 调研报告（WORD）写作模板

> 依据 4 份真实报告提炼。判型规则：出现"调研/现状/问题分析/经验总结"→调研报告体；去掉问题清单、放大成果数字→汇报体（走 reference-report.md）。

> **使用约定**：本文件只写规则与占位骨架；`〔 〕`为结构占位，`【 】`为用户未提供的事实。需要语感时读 `examples/语感示例.md`，其中内容不得复用。
>
> **免责声明**：本文示例均为体例演示，已脱敏或虚构，不涉及真实文档与真实数据。

## 0. 提问清单（生成前必问）

1. 亚型：现状调研型（有实地调研过程）／专题研究型（技术/事件解读）／举措研究型（政策梳理+方向清单）？
2. 调研过程数据（现状型必需）：去了哪些单位/多少人/多久/发现多少项问题/现场解决多少？——调研数据精确到个位以示工作扎实
3. 问题清单：问题N条，每条能否给出"（案例：XX公司……）"佐证？
4. 对标对象：外部（〔行业头部企业/产品〕）还是系统内同业（〔兄弟单位互为标杆〕）？
5. 建议分层：按要素/维度还是按层次？要不要带"（时间节点；责任单位；配合单位）"？
6. 是否作为简报附件（编号"附件N"嵌入更大材料包）？

## 1. 现状调研型（标准五段式）

### 完整骨架
```
（标题页：XXX调研分析报告 / 〔YYYY年M月〕）
一、总体情况（背景段四要素：目的、组织、范围、方式+成果数字）
  目的用排比动词短语："以'〔四字动宾〕、〔四字动宾〕、〔四字动宾〕、〔四字动宾〕'为调研指导"
  例："选定〔N〕个省份……〔N〕个调研小组于〔起止日期〕分别赴上述省份开展调研，
  采用〔方式1〕、〔方式2〕等多种方式，深入〔N〕个单位，调研覆盖〔N〕个专业共〔N〕名人员……
  共发现……〔N〕项，现场解决……〔N〕项。"
二、现状分析
  （一）要素支撑情况（1.〔要素1〕 2.〔要素2〕…，每段"一是…二是…三是…"）
  （二）应用推广现状-重点场景（N个场景逐一：建设进展→应用情况→问题→建议）
  （三）应用推广现状-其他场景
三、问题分析（用"问题卡"模板，见下；问题N跨章连续，分"（阻滞性问题）/（一般性问题）"）
四、经验总结
  （一）工作启示（启示N条，每条固定四段卡，见下）
  （二）亮点工作（按主题分栏综述，每条末标"典型经验来源：〔单位1〕、〔单位2〕等"）
五、下一步工作建议（按维度分大条，每条括注责任矩阵）
附件1 各单位要素现状调研情况（另附）
附件2 问题及建议清单（另附）
附件3 现场协助解决问题情况（表：序号/问题类型/问题描述/原因分析/解决措施/解决人员）
附件4 重点场景应用现状详情（大表：场景名称/功能完成度/资源保障/应用方式/应用范围频率/应用效果/用户评价/牵头人）
```

### 问题卡模板（全文统一）
```
问题N：标题句（定性括注）（阻滞性问题/一般性问题）
问题说明：现象描述。（案例：XX公司在XX场景中发现/反馈……具体数据）
原因分析：一是……；二是……；三是……
解决建议：一是……；二是……；三是……
```
例："问题1：〔能力/机制〕仍是制约〔场景〕应用见效的重要因素（阻滞性问题）……（案例：〔单位〕在〔场景〕中发现〔模型/系统〕存在〔问题表现〕……）"

### 启示卡模板
```
工作启示N："观点判断句（加引号）"
以XX公司……为典型经验，验证了这一观点。
具体做法：一是……二是……三是……
由此可见……（回扣观点）
```

### 建议格式（准工作方案）
每条 = 动词短语+成效预期 + 括注责任矩阵："（时间节点：〔起止时间〕；责任单位：〔单位〕；配合单位：〔单位〕）"
四大条惯例（按"要素保障→系统集成→推广运营→团队建设"逻辑展开，标题统一为动宾双句）：`（一）〔动宾〕，〔动宾〕 →（二）〔动宾〕，〔动宾〕 →（三）〔动宾〕，〔动宾〕 →（四）〔动宾〕，〔动宾〕`

## 2. 专题研究型（如"XX模型研究与解读"）

压缩版研究报告，常编号"附件N"嵌入材料包：
```
附件N
XXX研究与解读
摘要：（事件背景+结论判断："〔技术/模式突破点〕……
      已实现〔行业地位/效果判断〕……为公司〔业务方向〕提供了〔价值判断〕"）
一、XX基础介绍（紧扣技术要点一段一论点，配"图1"；横向对比定调："相较〔对标产品A〕
    与〔对标产品B〕……在……榜单中……最终实现〔对比结论〕"）
二、对XX工作的启发和思考
  （一）观点式长标题（动宾长句+目的句双联）
  （二）…… （三）……
  —— 每条正文引用具体数据（"〔数据示例〕"）落回公司自身工作
     （"帮助拓展〔公司模型/平台〕的能力""反哺至〔公司模型/平台〕"）
```

## 3. 举措研究型（战略方向研究）

```
XXX重点举措研究
一、XXX的战略价值（深度解读，四维排比：（一）创新应对〔行业〕复杂挑战
    （二）推动〔业务〕模式变革（三）驱动〔管理〕治理升级（四）推进〔技术〕业务化）
二、XXX重点方向（按层次化框架排方向）
  （一）基础支撑层：方向一 XXX / 方向二 XXX / ……
  （二）通用能力层：方向八 XXX / ……
  （三）智能应用层：方向十二 XXX / ……
  —— 每个方向 = 现状痛点 + "必须/应/亟需"导向句 + 路径描述
三、创新机制与重点举措（机制四件套：（一）创新统筹推进机制（二）健全技术创新与人才机制
    （三）构建开放合作生态（四）健全激励约束的考核评价体系）
  机制名词库："赛马制""揭榜挂帅""场景清单制+标杆负责制""月度复盘、季度评估、年度考核"
结尾总括句："形成〔A〕、〔B〕、〔C〕、〔D〕、〔E〕的落地体系"
```

## 4. 论证手法

- **政策拔高**："深入贯彻国家发展〔领域〕决策部署，全面落实〔上级专项行动/工作要求〕"；注明发文机关和日期
- **外部对标**：与〔对标企业1/2/3〕对比；建议"对标外部效果较好的〔工具/产品〕"
- **系统内对标**：〔兄弟单位〕互为标杆："〔单位A〕〔指标〕可达〔数值〕""〔单位B〕〔指标〕提升至〔数值〕，较传统方式提升〔数值〕"；句式"以〔单位〕……为典型经验，验证了这一观点"
- **数据格式**：规模带括注"〔数量〕（〔容量〕）"；对比用压缩比"从〔A〕压缩至〔B〕"；调研数据精确到个位"〔N〕项""〔N〕名"

## 5. 与其他文体的转换关系

- 调研报告"下一步工作建议"自带时间节点责任单位 = 工作方案雏形；写方案时可直接引用问题卡作依据
- 同一素材两用：保留调研过程与问题清单 = 调研报告；删除问题、放大成果数字、冠"工作思路/典型做法/下一步安排" = 工作汇报（见 reference-report.md）
- 专题研究简报 = 调研报告压缩版，"启发思考"章与"经验总结"章功能等价

## 6. 生成后自检（文体专属；数据/时间/称谓/引文/残留等硬伤按 SKILL.md 第五步 A 级核对，此处不重复）

- [ ] 问题卡四段齐全（说明含案例、原因一二三、建议一二三）、编号连续、分级标注
- [ ] 启示用引号观点句+典型经验+回扣结构
- [ ] 建议带责任矩阵括注；附件表头规范
- [ ] 对标有出处；数据有对比基准
