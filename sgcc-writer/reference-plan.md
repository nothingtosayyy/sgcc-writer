# 工作方案（WORD）写作模板

> 依据 12 份真实方案提炼。文风共性见 reference-style.md。

> **使用约定**：本文件只写规则与占位骨架；`〔 〕`为结构占位，`【 】`为用户未提供的事实。需要语感时读 `examples/语感示例.md`，其中内容不得复用。

## 0. 提问清单（生成前必问）

1. 亚型判断（给选项）：年度工作方案／建设专项方案／落实型方案／运营方案／思路举措／流程规范
2. 依据：上级文件文号／领导指示原话／会议要求？（导语必需，没有则写"为落实公司XX工作部署"）
3. 量化目标：到X年底实现什么数字？（至少3个指标）
4. 任务维度：按〔要素／专业／板块，由用户给出〕切分？
5. 组织分工：谁牵头、谁配合？（实名职务或单位名）
6. 时间节点：关键里程碑（X月底前完成XX）
7. 是否需要附件：任务清单表／指标体系表／人员名单？

## 1. 通用骨架（四段式+）

```
标题（居中，长标题分两行；下一行单位署名或年月）
[导语段 80–150字] 依据引用 → 背景/问题一句 → 目的句 → "特制定本工作方案。"
一、工作目标（一段成文150–350字，嵌3–8个量化指标，收尾"支撑X，为公司Y筑牢Z"）
二、工作思路（先一句数字口诀总起，再"XX方面"分2–5段，每段40–80字以"以X为Y"开头）
三～N、主体任务（按要素/专业/板块切（一）（二）（三）；任务1.2.3.连续编号）
末章、保障机制（3–5条对仗双句标题）
附件（数据表/任务计划甘特表/指标体系表/人员名单，按需）
```

**铁律**：
- 进度不单独成章，一律内嵌任务尾部："工作计划：X月底前，完成……"
- 任务N编号跨章连续，不按章重置
- 每个任务条目300–600字，固定三件套：

```
任务N：动宾短语标题
工作内容：一是……二是……三是……
工作计划：〔年份〕〔月〕底前，完成……；〔年份〕〔月〕底前，完成……
责任分工：〔牵头单位〕牵头，〔配合单位〕配合。
```

## 2. 六亚型骨架差异

### 2.1 年度工作方案
```
[导语] "〔上一年份〕，〔单位〕已建成……（上年总结）。……现制定本方案。"
一、工作目标（全年量化）
二、工作思路（数字口诀，如"〔动宾三字、动宾三字、动宾三字〕"）
三、工作内容（按职能板块分（一）～（N），每板块下1.2.3.任务+月度节点"1月，完成……"）
四、保障机制
```
细节：任务后可括注责任人（由用户提供姓名）："（一）〔任务名称〕（责任人：XXX）"。公司级年度方案为"满配"，加"现状与问题分析、技术发展趋势、工作组织及分工建议"等章，任务按1–N连续编号。

### 2.2 建设/专项方案
```
一、建设目标
二、建设思路（（一）～（五）条目式，每条四~六字动宾短语小标题："（一）加强沟通协同。（二）明确攻坚路径。"）
三、建设内容（"共性能力建设+专业应用场景建设"切分，再按技术范式分类）
四、实施路径（（一）第一阶段：重点攻坚／（二）第二阶段：全面推进）
五、组织保障
```
最小单元两段式："建设内容：一是…二是…／建设计划：〔月〕底前，……〔月〕底前，……〔月〕底前，……"

### 2.3 落实型方案
```
[导语] "根据〔领导职务〕在XX会议发言要求，针对'……'问题，为……，特制定本方案。"
一、工作背景及现状（（一）工作背景（二）现状分析）
二、工作目标及思路（一段式："按照'〔四字口诀、四字口诀、四字口诀〕'的工作思路，……"）
三、工作组织（领导组/工作组，组长姓名+职务由用户提供："组长：〔姓名〕〔职务〕"）
四、工作任务（（一）（二）（三）二级标题即"以X为抓手，动宾口号"排比句；每级下任务N三件套）
五、保障措施
```
独有特征：必引文号或领导指示；末章可用"有关要求"四段式替代保障措施（见2.6注）。

### 2.4 运营方案
```
一、概述（背景及现状+运营思路及目标）
二、组织与职责（N个组，每组"组成：…／职责：…"）
三、工作内容（按运营对象分块，第三层用文字小标题，每小节"目标句开头+一是二是+计划安排收尾"）
四、保障机制
附件：人员名单表（含姓名手机号）、运营指标表（指标名称/指标说明/计算方式/统计周期/指标类型五列）
```
问题导向变体（某类运营方案）：各业务板块分别走"（一）当前现状（含表格+"综上，…"小结）／（二）存在问题（问题N跨章连续）／（三）目标思路／（四）工作任务（任务N三件套）"四段循环，全文N张表。

### 2.5 思路举措/汇报类
```
标题+单位署名+导语"……具体汇报如下。"
一、背景问题（一是…二是…三是…，每条"现状描述+原因在于"）
二、目标思路
三、核心举措（按维度分（一）～（四），每维先"构建'〔A〕、〔B〕、〔C〕'的〔体系名称〕"总起，再列任务：实现目标/具体内容/责任单位/时间计划）
四、保障机制
```
上会审议材料外层封皮："〔会议名称〕会议材料／第XX次／会议材料之一 〔YYYY年M月D日〕"，正文"一、工作目标 二、工作过程（按日期列节点）三、工作内容"，收尾"现提请〔会议名称〕审议。附件：……"，方案本体作附件。

### 2.6 流程规范类
```
一、职责分工（领导组/管控组（PMO）/资源组/运营组/技术组；角色写"运营组-服务经理"组-岗连字符式）
二、运营工作概述
三、运营活动（每活动五段：1.工作定义 2.工作流程（图） 3.工作内容（1）（2） 4.业务指标（三列表格） 5.业务文档；无则显式声明"本项工作不涉及业务指标。"）
附件1–N：台账、审批单、交接单（含"负责人签字： 日期： 年 月 日"栏）
```

## 3. 保障措施标准条目库（选3–5条）

每条 = **对仗双句标题**（加强组织领导，强化工作落实）+ 一句定位 + 一句举措 + 一句落效。

| 条目 | 例句骨架 |
|---|---|
| 组织保障 | "〔牵头单位〕作为牵头单位，负责把控……工作的进度和质量" |
| 人员保障 | "依托〔专项团队〕，组建……专班，实施'挂图作战'"；"打造'〔A〕+〔B〕+〔C〕'核心人才梯队" |
| 技术保障 | "引入〔头部科技企业〕专家团队驻场支撑" |
| 机制保障 | "建立'周管控、月督导'工作机制""实行月度调度、季度通报" |
| 考核激励 | "建立过程督导与积分激励机制，实行积分晾晒""综合运用平时考核、年度考核、专项考核" |
| 安全合规 | "严格遵守国家网络信息安全相关政策法规……保障任务安全合规" |

落款提醒：落实型倾向"保障措施"、运营型倾向"保障机制"、会议审议类倾向"工作要求"（四段式："高度重视，深化认识。／压实责任，细化分工。／健全机制，强化协同。／注重实效，赋能应用。"，每条四字对句独立成段）；末条必落"落地见效"："确保运营机制落到位、各项工作见实效"。

## 4. 功能骨架范例（公司级年度方案·满配版）

只保留章节功能，不绑定业务对象；具体章名由主题决定。

```
〔单位〕〔年份〕〔主题〕工作方案
[导语段]
一、现状与问题分析（（一）建设现状（二）问题分析）
二、技术/行业发展趋势（按〔维度1〕/〔维度2〕/〔维度3〕…分N段排比）
三、目标思路（（一）工作目标（二）工作思路（三）〔要素〕协同关系 [图1]）
四、〔核心领域〕能力建设（按〔维度〕分（一）～（N） → 任务1–X）
五、〔支撑平台/体系〕建设（（一）定位与架构规划 [图2、图3]（二）年度重点工作 → 任务X+1–Y）
六、〔运营/保障体系〕建设（任务Y+1）
七、工作组织及分工建议（〔牵头部门〕/〔业务部门〕/〔支撑单位〕/〔省（市）公司〕/〔产业单位〕逐一定职责 [图4]）
八、保障机制（（一）〔机制1〕（二）〔机制2〕（三）〔机制3〕（四）〔机制4〕）
```

## 5. 生成后自检（文体专属；数据/时间/称谓/引文/残留等硬伤按 SKILL.md 第五步 A 级核对，此处不重复）

- [ ] 导语有依据引用且以"特制定本工作方案"收尾
- [ ] 目标章一段成文、含3个以上量化指标、以"支撑X，为公司Y筑牢Z"收尾
- [ ] 思路章有数字口诀且首次出现括注展开
- [ ] 每个任务三件套齐全（内容/计划/分工），时间用"X月底前，完成"
- [ ] 任务N跨章连续；保障条目对仗标题；无落款
